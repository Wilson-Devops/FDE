# CLOUD BINARY FDE Hands-On Labs
Welcome to the hands-on Forward Depoly Engineer learning repository.

This repository contains practical labs designed to help students learn cloud,
DevOps, CI/CD, Infrastructure as Code, automation, troubleshooting, and deployment
through real implementation exercises.

---

## 🎯 Learning Objectives

Students will gain hands-on experience with:

- AWS Cloud
- Linux
- Git and source control
- CI/CD
- AWS CodeCommit
- AWS CodeBuild
- Amazon S3
- Amazon EC2
- AWS IAM
- AWS Systems Manager
- Terraform
- Docker
- Kubernetes
- Infrastructure automation
- Troubleshooting and debugging
